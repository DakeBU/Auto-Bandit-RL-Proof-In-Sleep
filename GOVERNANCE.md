# Community governance

BanditRLlib uses the ABRL open-proposal, reviewed-integration model.

- Anyone may propose a sourced result, report a missing assumption, improve a
  teaching explanation, or submit a lemma packet.
- Contributors receive persistent credit for specific accepted work; this does
  not automatically imply ABRL paper authorship.
- Reviewers may request changes to assumptions, statement equivalence,
  namespace, API shape, proof structure, documentation, tests, or attribution.
- Maintainers decide whether and when a proposal enters BanditRLlib. Integration
  requires the Lean project gate, website regeneration, review, and merge to
  `main`; a public packet alone is never integrated.
- Status disagreements are resolved by exact source statements, compiler
  output, dependency records, and review evidence.
- Credentials, private peer-review material, and sensitive personal information
  must not be posted publicly.

Maintainers may appoint domain reviewers based on sustained, technically sound,
respectful contributions. Governance changes use public pull requests.
