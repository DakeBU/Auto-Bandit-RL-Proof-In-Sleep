    Stochastic Gradient Bandit (Algorithm 1)

    Read top to bottom: each step supplies the state or proof fact used by the next one.

    1. 01
      Initialize θ

      Set θₖ,₁ = 0; the initial action law is uniform.

    2. 02
      Softmax law

      Set pₖ,ₜ proportional to exp(θₖ,ₜ) over the finite arms.

    3. 03
      Sample reward

      Draw Aₜ from pₜ and observe the selected arm's reward rₜ.

    4. 04
      Update θ

      Add η rₜ(1{Aₜ = k} − pₖ,ₜ) to every coordinate.

    5. 05
      Split regret

      Expected gap increments plus failure mass yield the finite-horizon bound.
