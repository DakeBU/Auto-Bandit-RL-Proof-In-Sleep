    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardTotalReturnConcentration

    This module generates complete reward-bearing episode batches with a policy selected from the preceding batch history. It retains that history while mapping the next-batch kernel, identifies the resulting dynamic sampled-return law through condDistrib and condExpKernel, and applies the conditional sub-Gaussian sum theorem across a fixed finite number of adaptive rounds.
