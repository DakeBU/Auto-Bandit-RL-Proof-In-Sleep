    Lean module · OFUL

    BanditRLProof.OFULConcreteHistoryRidgeSelection

    This module reconstructs the standard scalar-ridge OFUL state from an inclusive finite action/Real-reward history. It proves the complete finite-dimensional measurability chain and instantiates the measurable recursive selector without a caller-supplied score-measurability premise.
