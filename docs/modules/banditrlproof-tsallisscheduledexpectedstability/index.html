    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisScheduledExpectedStability

    This module transports the one-round ordinary-importance-weighted conjugate-potential bound through the generated scheduled action law. Round n + 1 uses eta (n + 1), so the finite sum can vary the learning rate without weakening the deterministic stability theorem.
