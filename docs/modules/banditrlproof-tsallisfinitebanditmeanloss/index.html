    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFiniteBanditMeanLoss

    This module turns a bounded finite-bandit mean-reward model into the history-independent predictable loss family 1 - mean. Its loss differences are exactly the model gaps, so the compiled square-root-schedule fixed-gap theorem applies without a caller-supplied predictable gap law.
