    Lean module · UCB

    BanditRLProof.Algorithms.UCBFixedPolicyTelescopingAnytimeRegret

    This module defines one finite-arm UCB policy. Its score at history index t uses the summable confidence share telescopingConfidenceShare delta t / K; no terminal horizon occurs in the policy, state, score, or generated-action declarations. Finite horizons occur only in downstream count and regret consumers.
