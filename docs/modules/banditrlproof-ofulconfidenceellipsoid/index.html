    Lean module · OFUL

    BanditRLProof.OFULConfidenceEllipsoid

    This module consumes the common-R vector self-normalized tail. It defines the finite-horizon ridge estimator from scalar observations, proves its exact error decomposition into the martingale score and regularization bias, and transports the score tail to a parameter confidence ellipsoid.
