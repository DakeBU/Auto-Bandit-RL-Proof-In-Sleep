    BanditRLProof.Exp3MixedSquarePredictableVariance

    This module promotes the exact finite-action centered second moment used by the fixed-tilt Bernstein proof to an explicit generated predictable process. It supplies the variance-process input needed by a future local Freedman iteration without claiming that such a tail theorem already exists in Mathlib.
