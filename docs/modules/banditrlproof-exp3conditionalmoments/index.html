    Lean module · EXP3

    BanditRLProof.Exp3ConditionalMoments

    This module turns the finite weighted-sum identities for the EXP3 estimator into Bochner-integral identities under an actual history-conditional action law. The conditional distribution is represented by a Markov kernel whose values are explicit finite sums of Dirac measures.
