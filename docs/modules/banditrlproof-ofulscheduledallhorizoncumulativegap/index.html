    Lean module · OFUL

    BanditRLProof.OFULScheduledAllHorizonCumulativeGap

    This module combines the one-policy all-time scheduled confidence event with a deterministic varying-budget radius-width envelope. The terminal event quantifies over every finite horizon but is absorbed by the same all-time confidence failure event.
