    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticSelfConsistentCausalSource

    The compiled self-consistent finite-window theorems vary the batch size and algorithm parameters with the outer window index. Their laws therefore are not prefixes of one fixed adaptive source. This module defines the distinct causal algorithm in which those parameters vary at each trajectory coordinate.
