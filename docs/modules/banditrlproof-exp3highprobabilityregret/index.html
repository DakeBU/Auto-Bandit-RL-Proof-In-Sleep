    Lean module · EXP3

    BanditRLProof.Exp3HighProbabilityRegret

    This module completes the finite-horizon high-probability pseudo-regret route for the generated predictable EXP3 trajectory. A pathwise reciprocal-floor bound controls the random estimator-square sum almost surely. The final theorem then combines the sampled Hedge inequality, exploration bias, the pure-Hedge predictable-minus-observed confidence event, and the comparator-estimator confidence event by a two-event union bound.
