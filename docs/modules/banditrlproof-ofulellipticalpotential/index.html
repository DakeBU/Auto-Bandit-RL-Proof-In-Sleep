    BanditRLProof.OFULEllipticalPotential

    This module records the deterministic finite-dimensional linear-algebra surface needed by OFUL/LinUCB routes. It packages rank-one and finite-history feature Gram matrices, positive-definiteness and inverse facts, determinant updates, log-determinant telescoping, trace/eigenvalue determinant bounds, and the standard logarithmic clipped elliptical-potential endpoint.
