    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeInverseSqrtCalibration

    This module calibrates the cumulative count-martingale confidence producer to a concrete count-dependent optimistic planner. Path-support exploration gives every adaptive batch a common predictable visit floor. Outside the compiled global count event, the accumulated realized visits exceed that predictable floor minus the cumulative confidence radius.
