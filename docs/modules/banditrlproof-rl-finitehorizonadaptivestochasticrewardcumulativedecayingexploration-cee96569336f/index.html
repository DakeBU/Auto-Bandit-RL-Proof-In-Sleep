    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardCumulativeDecayingExplorationCommonSpaceConsistency

    The compiled stochastic cumulative route gives a sharp certificate on each scheduled finite-window trajectory space. This module places those complete finite-window experiments on one dependent infinite product and proves that the scheduled stochastic realized-regret process converges to zero in measure.
