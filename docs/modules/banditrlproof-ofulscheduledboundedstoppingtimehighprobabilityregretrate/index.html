    BanditRLProof.OFULScheduledBoundedStoppingTimeHighProbabilityRegretRate

    This module evaluates the explicit one-policy all-horizon OFUL rate at a bounded stopping time. The probability argument is pathwise event domination, not optional stopping and not a new union bound.
