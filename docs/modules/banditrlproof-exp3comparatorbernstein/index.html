    Lean module · EXP3

    BanditRLProof.Exp3ComparatorBernstein

    This module replaces the range-squared Hoeffding proxy for one fixed comparator estimator by a fixed-tilt second-moment bound. The scalar input is the quadratic exponential remainder on [-1, 1]; the probabilistic input is the exact second moment of the importance-weighted estimator under its finite sampling law.
