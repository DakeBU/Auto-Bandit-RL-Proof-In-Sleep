    Lean module · Thompson sampling

    BanditRLProof.Algorithms.ThompsonBayesRegretDecomposition

    This module ports the probability-matching algebra behind LML's TS.integral_regret_eq_add to the locally generated Thompson trajectory. The confidence score is abstract but must depend only on the visible history and the candidate action. Clipped-UCB concentration can therefore be attached downstream without restoring an assumed sampler or posterior law.
