    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardCumulativeDecayingExplorationConsistency

    This module lifts the cumulative empirical-optimistic exploratory source to complete stochastic-reward episode batches. Policy selection reads only the known-reward projection of the sampled prefix. The first layer proves the exact complete trajectory pushforward to the deterministic cumulative source; later layers consume the deterministic decaying-exploration count certificate and the globally centered stochastic return tail.
