    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonNaturalCausalRealizedBehaviorRegretHighProbabilityBurninLogRate

    This module repairs the nonvanishing finite-prefix model budget in the fixed-prefix logarithmic realized-regret route. Model failures before a deterministic burnin are paid for by the uniform 2 * horizon behavior regret bound. Only the infinite model tail from burnin onward enters the probability event. The return component remains the fixed-prefix sum of successor-batch-average deviations, with each batch divided by its own positive scheduled episode count.
