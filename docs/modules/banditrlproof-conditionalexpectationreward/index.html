    BanditRLProof.ConditionalExpectationReward

    This module exposes a narrow COND-EXPECT-REWARD support leaf: if the conditional-expectation kernel already identifies the next centered reward law and its conditional integral is zero, then the ordinary conditional expectation of that centered reward is zero.
