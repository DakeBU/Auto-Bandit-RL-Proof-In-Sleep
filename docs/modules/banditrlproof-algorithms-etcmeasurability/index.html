    theorem BanditRLProof.ETC.prob_exists_ne_bestArm_empMean_ge_bestArm_le_sum Compiled

    The finite existential wrong-mean event is bounded by the finite sum of its guarded pairwise arm events. This is an outer-measure finite-union wrapper.
