    This module upgrades each fixed-index genuine hittingAfter first passage from a first moment to OFUL.SquareIntegrableFiniteStoppingTime when 4 < mdp.horizon. Squaring the fourth-power checkpoint values produces a seventh-degree block weight. The stronger horizon contract supplies an inverse-tenth local confidence share, leaving a summable inverse-square diagonal after shifted-tail reindexing.
