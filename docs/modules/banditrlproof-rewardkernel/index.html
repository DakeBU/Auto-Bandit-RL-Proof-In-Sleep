    BanditRLProof.RewardKernel

    This module records a narrow KERNEL-REWARD leaf: a reward law is represented as a Mathlib Markov kernel indexed by an arm/context object. It exposes the kernel and the measurability/probability regularity facts needed by later policy-kernel and trajectory-law leaves, but it does not bind kernels or build a trajectory measure.
