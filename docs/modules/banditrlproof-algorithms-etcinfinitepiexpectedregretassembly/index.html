    BanditRLProof.Algorithms.ETCInfinitePiExpectedRegretAssembly

    This module instantiates the abstract lower-integral wrong-commit regret assembly with the concrete finite-argmax oracle and the infinite-product bounded-reward wrong-commit probability bound. The Real/Bochner wrapper still remains fixed-product and fixed-exploration, not the final adaptive ETC theorem.
