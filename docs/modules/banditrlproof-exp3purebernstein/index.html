    Lean module · EXP3

    BanditRLProof.Exp3PureBernstein

    This module replaces the range-squared Hoeffding proxy for the pure-Hedge cross-weighted estimator by a fixed-tilt second-moment budget. The sign is predictable pure loss - observed cross-weighted loss, as consumed by the sampled Hedge regret decomposition.
