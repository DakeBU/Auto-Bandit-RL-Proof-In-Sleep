    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeInverseSqrtNormalizedRate

    This module specializes the explicit two-scale calibration to rewards bounded in absolute value by one. It fixes the zero-count budget to one, chooses the inverse-square-root scale from the logarithmic factor and visit floor, and replaces both scalar calibration premises by one episode threshold.
