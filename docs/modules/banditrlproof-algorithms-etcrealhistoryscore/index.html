    BanditRLProof.Algorithms.ETCRealHistoryScore

    This module mirrors the finite-pair-history pullCount', sumRewards', and empMean' score surface used by the pinned LML ETC source. It identifies that history score with the existing native Real exploration score, then feeds the history-shaped commit law into the exact source adapter.
