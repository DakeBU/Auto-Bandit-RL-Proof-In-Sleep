    Lean module · UCB

    BanditRLProof.Algorithms.UCBConditionalRewardPairTrajectorySampledAsymptotics

    This module runs the canonical pair-trajectory sampled-successor UCB theorem with confidence budget 1 / (T + 1), proves logarithmic expected pseudo-regret for fixed model data, and derives vanishing expected average pseudo-regret for the resulting horizon-indexed policy family.
