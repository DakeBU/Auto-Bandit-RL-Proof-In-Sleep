    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonOptimality

    This module adds finite-action maximization to the compiled policy-evaluation route. On a finite discrete state space, the pointwise finite argmax is a measurable deterministic selector. The resulting greedy Markov policy attains the backward optimal value, which dominates every Markov policy value.
