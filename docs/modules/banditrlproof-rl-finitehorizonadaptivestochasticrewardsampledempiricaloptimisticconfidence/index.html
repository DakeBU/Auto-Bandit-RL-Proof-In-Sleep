    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticConfidence

    This module transports the fixed-policy sampled count-and-reward empirical model event through the exact history-fiber laws of the adaptive stochastic source. The resulting finite-round event controls models computed from the actual sampled rewards, not their known-mean projection.
