    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonIIDSimultaneousCountConfidence

    This module puts every finite visit and joint-transition count coordinate into one index type and applies an equal-share finite union bound to the compiled fixed-coordinate tails. The route remains fixed-policy iid. It does not form visit-conditioned ratios or claim adaptive, anytime, or cumulative regret.
