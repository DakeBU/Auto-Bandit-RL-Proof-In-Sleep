    Lean module · UCB

    BanditRLProof.Algorithms.UCBConditionalRewardLawPolicy

    This module constructs a reward-history-generated finite-arm UCB policy whose score is exactly the realized-count score from UCBConditionalRewardLaw. Successor actions 1, ..., K initialize every arm once. Later actions maximize the practical random-width index computed from the inclusive pair history.
