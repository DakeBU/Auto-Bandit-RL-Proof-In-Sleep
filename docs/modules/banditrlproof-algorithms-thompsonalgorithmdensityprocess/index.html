    BanditRLProof.Algorithms.ThompsonAlgorithmDensityProcess

    This module ports the process-facing core of LML's algorithm-density theorem. Two stochastic history policies interact with the same feedback environment. If every actual action law is absolutely continuous with respect to the reference action law, the actual finite action/reward history law is the reference history law weighted by the recursive product of policy Radon-Nikodym derivatives.
