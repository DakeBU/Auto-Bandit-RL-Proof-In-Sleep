    Lean module · UCB

    BanditRLProof.Algorithms.UCBArmStreamSource

    This module implements the pathwise reward-consumption rule used by the pinned LML UCB route. Whenever an action is selected, the observed reward is the next unused coordinate of that arm's latent stream. Consequently, the selected reward sum is exactly the stream prefix whose length is the realized pull count, so it supplies FixedArmPrefixSource without an extra pathwise hypothesis.
