    BanditRLProof.Algorithms.ETCRealArgmaxTie

    This module identifies the strict-update fold used by the native Real ETC route with the least-encoded maximizing arm selected by the Nat.find scheme used in LML's measurable argmax. It then assembles round-robin exploration, the commit action, and post-commit persistence into the action equality consumed by the exact native Real source-law theorem.
