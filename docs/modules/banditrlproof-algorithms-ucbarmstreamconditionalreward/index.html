    BanditRLProof.Algorithms.UCBArmStreamConditionalReward

    This module isolates the product-measure part of the selected-reward route. Every (pull index, arm) coordinate is independent of the function containing all other coordinates, so its conditional distribution given that complement is the prescribed stationary arm law.
