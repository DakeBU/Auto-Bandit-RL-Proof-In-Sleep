    BanditRLProof.TsallisSelfBounding

    This module records the paper-facing (Delta, C, T) self-bounding condition, identifies it on the generated predictable trajectory under an exact gap law, and proves the finite completion-of-squares conversion used after a refined suboptimal-arm stability bound is available.
