    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisSqrtScheduleSelfBoundingOptimization

    This module specializes the refined generated quadratic split to the local schedule eta_t = 1 / (2 * sqrt (t + 1)). The refined coefficient is replaced by its compiled 5 / sqrt (t + 1) envelope and the deterministic rate-square base is identified with one half of the harmonic budget.
