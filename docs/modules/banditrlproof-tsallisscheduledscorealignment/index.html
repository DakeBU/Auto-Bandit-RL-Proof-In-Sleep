    BanditRLProof.TsallisScheduledScoreAlignment

    This module identifies the recursively accumulated scheduled half-Tsallis history score with FTRL.cumulativeLoss of the actual observed importance-weighted loss vectors. It then rewrites the deterministic time-varying penalty theorem onto one generated trajectory sample.
