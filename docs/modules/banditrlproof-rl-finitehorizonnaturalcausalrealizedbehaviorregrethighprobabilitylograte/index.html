    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonNaturalCausalRealizedBehaviorRegretHighProbabilityLogRate

    This module converts the compiled fixed-prefix logarithmic behavior-expected regret route into a realized route on the same heterogeneous dependent causal source. Natural round t uses the sample average of the actual successor batch at coordinate t + 1, generated by the exploratory policy selected from the prefix through t.
