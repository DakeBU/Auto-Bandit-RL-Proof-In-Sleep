    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonStochasticRewardTotalReturnConcentration

    This module combines selected-reward noise with policy-action and transition noise. The target random variable is the actual sampled cumulative return minus the recursive policy value. The additive proxy relies on the product structure of reward and next-state sampling given the current state and action.
