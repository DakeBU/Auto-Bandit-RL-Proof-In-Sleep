    BanditRLProof.RL.FiniteHorizonStochasticRewardIIDAllCoordinateEmpiricalModelConfidence

    This module combines the compiled sampled-reward coordinate tail with the existing simultaneous count/transition event. It keeps the complete reward-bearing iid trajectory family as the probability space and constructs the empirical model from the actual sampled rewards.
