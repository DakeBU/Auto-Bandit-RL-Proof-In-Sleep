    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisRefinedSuboptimalStability

    The paper's refined stability term contains sum_a sqrt (p a) * (1 - p a). This module proves the finite-simplex elimination of one optimal arm and connects that bound to the compiled self-bounding completion-of-squares consumer.
