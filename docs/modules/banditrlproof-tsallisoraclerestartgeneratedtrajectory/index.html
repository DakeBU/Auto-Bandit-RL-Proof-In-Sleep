    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisOracleRestartGeneratedTrajectory

    This module constructs the restarted selector and trajectory kernel needed by the oracle-restart dynamic-regret route. It proves the conditional action law of that generated process. Epoch-local regret transport remains downstream.
