    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonNaturalCausalRealizedBehaviorRegretHighProbabilityExplicitSchedule

    This module chooses the concrete schedule scale n = n + 1, burnin n = scale n, rounds n = scale n ^ 4, and returnDelta n = exp (-scale n) for the compiled natural-causal burn-in terminal. The fourth-power prefix simultaneously absorbs the linear burn-in charge and the fixed-prefix normalized-return confidence radius.
