    BanditRLProof.Algorithms.ThompsonCanonicalTrajectory

    This module realizes a HistoryAlgorithm interacting with one fixed HistoryEnvironment on Mathlib's Ionescu-Tulcea trajMeasure. It proves both the combined action/reward process contract and the four split conditional-law fields used by the environment-indexed Thompson density route.
