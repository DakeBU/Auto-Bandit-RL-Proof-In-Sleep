    BanditRLProof.TsallisScheduledRefinedStabilityPenalty

    This module combines the generated small-rate stability budget with the uncollapsed refined expected penalty. It exposes one coefficient per actual time and feeds the resulting square-root upper bound to the exact fixed-gap self-bounding consumer.
