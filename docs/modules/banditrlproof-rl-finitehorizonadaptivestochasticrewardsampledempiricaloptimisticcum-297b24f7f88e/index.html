    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticCumulativeExploratoryBehaviorRegret

    This module charges uniform exploration around the actual sampled-model recommendations. The policy built from coordinate round is the adaptive source policy for successor batch round + 1; the initial policy and realized sampled returns remain outside this theorem route.
