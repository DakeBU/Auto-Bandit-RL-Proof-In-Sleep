    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisScheduledExpectedGapSelfBounding

    This module replaces the samplewise fixed-gap premise by the stochastic first-moment law actually needed by self-bounding. For every time and suboptimal arm, the probability-weighted predictable loss difference has expectation gap action * E[p_t(action)].

    def BanditRLProof.Tsallis.HasScheduledExpectedGapLaw Compiled

    The per-time, per-suboptimal-arm first-moment law needed by stochastic self-bounding. It is deliberately finer than the final summed regret law so that later conditional-expectation producers can discharge it one coordinate at a time.
