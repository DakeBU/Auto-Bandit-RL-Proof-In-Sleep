    BanditRLProof.Algorithms.UCBConditionalRewardLawRegret

    This module connects the explicit expected successor pull-count theorem to the local finite-bandit pseudo-regret surface. The regret action shifts generated coordinates 1, ..., T to the standard pull-count coordinates 0, ..., T-1.
