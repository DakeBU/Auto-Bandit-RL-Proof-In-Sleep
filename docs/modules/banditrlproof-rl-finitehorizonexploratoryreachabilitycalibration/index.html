    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonExploratoryReachabilityCalibration

    This module turns a generated stage-state probability lower envelope into the state/action expected-count margins needed by the adaptive empirical optimistic confidence route. Uniform exploration supplies only the action factor; state reachability and the transition-bonus cover remain explicit contracts.
