    BanditRLProof.Algorithms.ThompsonStationaryReward

    This module isolates the stationary feedback adapter and the algorithm-independent latent-arm-stream tail used by the Thompson Bayesian-regret route. The tail theorems deliberately quantify over an arbitrary action trace: only the next-unused-coordinate reward rule and the product arm-stream law matter.
