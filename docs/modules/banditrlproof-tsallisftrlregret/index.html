    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLRegret

    This module lifts the one-step explicit-minimizer API to a finite-horizon regularized be-the-leader theorem and the standard FTRL stability/penalty regret decomposition. It then specializes the regularizer to negative Tsallis entropy and exposes the penalty as a difference of finite power sums.
