    Lean module · EXP3

    BanditRLProof.Exp3MixedSquareExponentialRealizedExplicitTuning

    This module closes the remaining exploration-parameter leaf in the generated exponential mixed-square route. The interval sub-Gaussian proxy contributes a sixth-root scale because its range is |arms| / gamma; the two Bernstein radii contribute a cube-root scale, and the realized deviation contributes a square-root scale. The resulting rate is deliberately recorded as the output of the current Hoeffding-proxy route, not as a Freedman or EXP3.P rate.
