    Lean module · EXP3

    BanditRLProof.Exp3MixedSquarePredictableVarianceSmallLossRealizedMarkovHighProbabilityRegret

    This module bounds predictable loss-square energy by armwise predictable loss mass. It turns an almost-everywhere small-loss budget under the exact generated trajectory measure into the variance lintegral contract used by the Markov-closed realized regret route. Universal pathwise budgets remain valid as a special case via Filter.Eventually.of_forall.
