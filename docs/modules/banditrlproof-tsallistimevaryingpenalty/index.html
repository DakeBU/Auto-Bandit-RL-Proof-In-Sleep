    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisTimeVaryingPenalty

    This module formalizes the deterministic learning-rate-change term used by the Tsallis-INF penalty route. It telescopes paper-normalized half-Tsallis potential values across a positive, nonincreasing schedule and retains the negative terminal comparator contribution.
