    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonNaturalCausalAverageRealizedBehaviorRegretAlmostSureExplicitSchedule

    This module keeps the exact process which divides every successor batch by its own positive episode count and then weights rounds equally. Along the deterministic fourth-power prefixes (n + 1)^4, its compiled all-prefix L1 envelope is dominated by a sum of shifted exponent-three and exponent-two p-series. Markov's inequality and the first Borel-Cantelli lemma then give almost-everywhere convergence on this subsequence.
