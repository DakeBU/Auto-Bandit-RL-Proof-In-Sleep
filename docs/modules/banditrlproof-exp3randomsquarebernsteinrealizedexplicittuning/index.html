    BanditRLProof.Exp3RandomSquareBernsteinRealizedExplicitTuning

    The random-square theorem already tunes the learning rate independently of the exploration parameter. This module chooses the remaining exploration parameter from the two confidence scales at failure budget delta / 4 and obtains a fully explicit generated realized-regret threshold.
