    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonIIDCountConcentration

    This module applies the Mathlib-backed bounded-variable Hoeffding route to the fixed-policy iid episode-batch law. It proves two-sided confidence tails for one visit coordinate and one transition coordinate. Simultaneous finite coordinate events, random-denominator ratios, and adaptive episode policies remain downstream.
