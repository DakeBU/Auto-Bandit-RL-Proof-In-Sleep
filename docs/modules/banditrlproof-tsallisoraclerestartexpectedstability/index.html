    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisOracleRestartExpectedStability

    This module transports one restart-local half-Tsallis potential-stability term through the conditional action law of the single generated restart trajectory. The shifted trajectory is used only for pathwise reindexing; no fresh independent epoch law is introduced.
