    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeEpisodewiseCommonSpaceExpectedConsistency

    This module strengthens the independent-coordinate common-space convergence in probability theorem to convergence of expected absolute realized-behavior regret. The additional input is an almost-everywhere deterministic envelope: generated adaptive batches are reward-consistent, so every scheduled realized average regret has absolute value at most twice the horizon.
