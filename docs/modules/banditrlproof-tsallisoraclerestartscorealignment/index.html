    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisOracleRestartScoreAlignment

    This module identifies every actual restart probability and stored-reward importance-weighted loss with the corresponding scheduled surface after shifting to the current epoch's local time. It then exposes the pathwise FTRL certificate on any explicit contiguous prefix of one restart epoch.
