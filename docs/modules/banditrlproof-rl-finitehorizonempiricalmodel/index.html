    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonEmpiricalModel

    This module builds a genuine finite-state empirical transition kernel from a finite family of recorded episode steps. Positive visit counts are normalized into a finite PMF; zero visit counts use an explicit default-state Dirac PMF. The resulting empirical reward and transition model is then connected to the compiled coordinate-confidence optimistic-regret route.
