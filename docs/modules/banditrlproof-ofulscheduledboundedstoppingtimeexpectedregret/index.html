    BanditRLProof.OFULScheduledBoundedStoppingTimeExpectedRegret

    This module integrates the compiled bounded-stopping-time high-probability pseudo-regret theorem. Horizon monotonicity moves both the explicit scheduled budget and the deterministic gap envelope to the deterministic stopping-time bound. The expectation proof is an indicator decomposition, not optional stopping.
