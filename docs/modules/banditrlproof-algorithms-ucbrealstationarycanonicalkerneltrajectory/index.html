    Lean module · UCB

    BanditRLProof.Algorithms.UCBRealStationaryCanonicalKernelTrajectory

    This module packages the canonical arm-stream UCB split conditional laws as a history algorithm and environment, then independently regenerates their observable action/reward pair process with Mathlib's Ionescu-Tulcea Kernel.trajMeasure. The resulting coordinate process supplies every field of RealStationaryUCBSequence without a caller-provided sample space or law.
