    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisScheduledConditionalMeanGap

    This module exposes the sampling-before-action sigma-algebra at each scheduled time. The scheduled action probability is measurable with respect to that sigma-algebra, so Mathlib's conditional-expectation pull-out theorem turns a constant conditional loss-gap law into HasScheduledExpectedGapLaw.
