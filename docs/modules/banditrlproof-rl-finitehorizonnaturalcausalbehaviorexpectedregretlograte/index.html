    This module closes the symbolic finite-prefix envelope for the actual source.successorPolicyAt behavior on the one genuine heterogeneous dependent causal trajectory measure. The expanded coordinate rate has an inverse-square term, the scheduled exploration harmonic term, and a confidence term with exponent mdp.horizon + 5.
