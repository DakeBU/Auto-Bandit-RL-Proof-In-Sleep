    BanditRLProof.Algorithms.KLUCBBernoulli

    This file owns the project-local binary relative entropy used by KL-UCB. The codomain is ENNReal: singular Bernoulli comparisons are genuinely top, not the accidental finite value obtained from Mathlib's totalized Real.log 0.
