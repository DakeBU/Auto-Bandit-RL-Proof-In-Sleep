    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLExpectedStability

    This module sums the one-round conditional half-Tsallis stability theorem over a finite horizon under a common ambient trajectory measure. Conditional-law identification is used both for the one-round inequality and for transporting product-law integrability back to each realized history/action score.
