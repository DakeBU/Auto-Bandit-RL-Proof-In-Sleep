    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLMinimizerMeasurability

    The project minimizer is chosen noncomputably on the ambient action space, but the objective only sees the explicit finite arm set. We restrict the selected minimizer to that finite subtype and prove continuity in the restricted score vector. Compactness supplies cluster points and strict convexity identifies every cluster point with the unique minimizer.
