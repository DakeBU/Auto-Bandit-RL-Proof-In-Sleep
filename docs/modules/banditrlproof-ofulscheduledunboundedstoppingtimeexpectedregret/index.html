    Lean module · OFUL

    BanditRLProof.OFULScheduledUnboundedStoppingTimeExpectedRegret

    This module removes the deterministic stopping-horizon bound from the expected pseudo-regret interface. It retains the exact bad-event random-envelope integral: controlling that term by delta requires an additional moment or tail contract and is not a consequence of first-moment stopping-time integrability alone. This is an event decomposition, not optional stopping.
