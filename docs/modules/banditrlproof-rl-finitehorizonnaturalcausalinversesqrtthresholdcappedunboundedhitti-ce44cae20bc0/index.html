    BanditRLProof.RL.FiniteHorizonNaturalCausalInverseSqrtThresholdCappedUnboundedHittingAfterExpectedRegretTruncationReplacement

    This module transports the accepted capped/uncapped L1 truncation equivalence through the Bochner integral. The result compares signed expected stopped average realized behavior regret on the same generated trajectory law. It is not an optional-stopping or policy-value identity.
