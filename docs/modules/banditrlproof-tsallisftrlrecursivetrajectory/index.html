    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLRecursiveTrajectory

    This module builds the pure half-Tsallis finite-history policy and its Ionescu--Tulcea trajectory. The only selector-specific input is coordinate measurability of the canonical noncomputable minimizer for every measurable finite-history score. Simplex feasibility, score recursion, policy kernels, and conditional action laws are constructed locally.
