    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardEmpiricalOptimisticProjection

    This module lifts the existing known-reward exploratory empirical-transition source to stochastic rewards. Its policy selector reads only the complete known-reward projection of the observed stochastic prefix. The resulting adaptive stochastic trajectory therefore maps exactly to the deterministic source trajectory, so the compiled count-confidence, optimism, and recommended expected-regret terminal can be pulled back without estimating sampled rewards.
