    Lean module · UCB

    BanditRLProof.Algorithms.UCBRealHistoryIndex

    This module mirrors the path-dependent score used by the pinned LML UCB route. In particular, the confidence width divides by the realized pull count. It is therefore distinct from the earlier UCB surface whose proxy is deterministic in the sample point.
