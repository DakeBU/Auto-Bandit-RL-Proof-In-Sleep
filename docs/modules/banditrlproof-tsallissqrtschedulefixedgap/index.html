    BanditRLProof.TsallisSqrtScheduleFixedGap

    This module instantiates the scheduled refined stability-penalty theorem with eta t = 1 / (2 * sqrt (t + 1)). The schedule contracts and its unified coefficient are bounded explicitly before the fixed-gap theorem is consumed.
