    BanditRLProof.Algorithms.StochasticGradientBanditTheoremTwoNthPull

    Appendix C of Baudry--Johnson--Vary--Pike-Burke--Rebeschini reindexes the optimal-arm dynamics by the number of times that arm has been selected. The generated Lean trajectory is instead indexed by chronological time. This module supplies the missing bridge without assuming that the adaptively selected reward subsequence is IID.
