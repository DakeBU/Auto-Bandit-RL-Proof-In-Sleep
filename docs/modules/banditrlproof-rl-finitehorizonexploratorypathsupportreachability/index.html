    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonExploratoryPathSupportReachability

    This module derives a policy-independent state-probability lower envelope from explicit initial singleton floors and one chosen predecessor transition for each successor-stage state. Uniform exploration supplies the chosen action's probability. The resulting envelope applies to every exploratory policy table and therefore to every behavior policy in the adaptive empirical optimistic source.
