    Lean module · EXP3

    BanditRLProof.Exp3HedgeRegret

    This module closes the full-information exponential-weights/Hedge potential argument that sits immediately below EXP3. It defines weights from cumulative losses, normalizes them on an explicit nonempty finite action set, proves the one-step logarithmic potential inequality, and telescopes it into second-order and [0,1] finite-horizon regret bounds.
