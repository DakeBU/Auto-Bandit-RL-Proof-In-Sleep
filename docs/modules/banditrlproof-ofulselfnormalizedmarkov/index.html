    BanditRLProof.OFULSelfNormalizedMarkov

    This module consumes the evaluated Gaussian-mixture lintegral <= 1 and converts it into a probability bound. It then transports the paper-facing inverse-Gram/log-determinant bad event into the Markov threshold event.
