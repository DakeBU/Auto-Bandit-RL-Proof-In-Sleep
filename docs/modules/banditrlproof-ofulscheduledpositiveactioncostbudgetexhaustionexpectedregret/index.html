    Lean module · OFUL

    BanditRLProof.OFULScheduledPositiveActionCostBudgetExhaustionExpectedRegret

    This module specializes the cumulative positive-cost budget-exhaustion route to a deterministic Nat-valued cost on the finite action set. At round t, the cost process reads the current action from the canonical generated trajectory.
