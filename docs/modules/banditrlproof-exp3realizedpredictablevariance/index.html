    BanditRLProof.Exp3RealizedPredictableVariance

    This module replaces the fixed interval proxy for the selected-loss deviation by its exact finite-action centered second moment. It constructs the generated predictable variance process and the zero-budget conditional MGF of the variance-compensated realized deviation.
