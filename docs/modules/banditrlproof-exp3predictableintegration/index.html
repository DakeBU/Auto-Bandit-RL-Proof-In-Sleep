    BanditRLProof.Exp3PredictableIntegration

    This module connects the pathwise sampled-Hedge inequality to the generated predictable trajectory moments. The key law transport uses the exploration distribution p_t to sample an action while a distinct predictable pure-Hedge distribution q_t weights the importance-weighted estimator.
