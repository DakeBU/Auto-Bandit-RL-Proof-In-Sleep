    Lean module · OFUL

    BanditRLProof.OFULGeneratedTrajectoryConfidenceGap

    This module identifies the scalar-ridge state reconstructed from an inclusive finite pair history with the generic finite-horizon state on the underlying trajectory. It then transports the measurable strict-fold selector's score maximality to one-step and finite successor-window optimism-gap bounds.
