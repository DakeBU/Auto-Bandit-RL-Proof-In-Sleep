    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonNaturalCausalAverageRealizedBehaviorRegretL1Consistency

    This module controls the exact natural process which first normalizes every successor batch by its own positive episode count and then weights rounds equally. It is not the total-episode-mass-weighted process from the earlier L1 route. The argument exposes the cumulative normalized-return MGF, obtains a first-moment inverse-square-root bound, and combines it with the compiled logarithmic behavior expected-regret rate.
