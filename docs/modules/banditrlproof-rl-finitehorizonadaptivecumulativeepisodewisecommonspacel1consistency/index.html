    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeEpisodewiseCommonSpaceL1Consistency

    This module packages the compiled expected absolute realized-regret convergence in Mathlib's native MemLp, eLpNorm, and Lp interfaces. The underlying probability space is still the independent product of complete scheduled finite-window experiments; no nested causal coupling is constructed here.
