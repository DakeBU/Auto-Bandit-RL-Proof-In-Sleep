    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonStochasticRewardInitialLawTotalReturnConcentration

    This module lifts the statewise sampled-return concentration theorem to the full stochastic trajectory measure generated from a finite initial-state law. The random variable remains centered by the recursive value of its own initial state; no concentration claim is made for mixing those state-dependent values.
