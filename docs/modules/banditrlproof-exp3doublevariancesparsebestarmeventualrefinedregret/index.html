    Lean module · EXP3

    BanditRLProof.Exp3DoubleVarianceSparseBestArmEventualRefinedRegret

    For fixed model parameters, the four deterministic large-horizon inequalities used by the exact double-predictable-variance sparse EXP3 schedule eventually hold automatically. This module therefore removes the coarse T + 1 fallback eventually, identifies the best-arm threshold with 16 * gamma_T * T, and reuses the existing off-sparsity, residual, and practical tails under the same horizon-indexed generated trajectory measures.
