    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFiniteArmIIDCorruptedRewardLaw

    This module replaces the free nonnegative corruption parameter of the abstract self-bounding endpoint by a quantity derived from a concrete process. Each arm receives a fixed real reward shift, the shifted reward is projected back to [0, 1], and fresh finite reward vectors remain IID across rounds.
