    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeInverseSqrtAverageConsistency

    This module chooses an explicit natural number of exploratory episodes per batch. The schedule simultaneously clears the normalized calibration threshold and places the logarithmic factor below one batch's visit mass. The resulting scalar average recommendation-regret bound is at most a fixed constant times 1 / sqrt(rounds) and therefore tends to zero.
