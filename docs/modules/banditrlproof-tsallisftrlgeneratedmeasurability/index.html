    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLGeneratedMeasurability

    This module derives measurability of the generated one-round stability score from coordinate measurability of the current and updated half-Tsallis selectors. The updated selector remains noncomputable, so its coordinate measurability is kept as an explicit selector contract rather than inferred from Classical.choose.
