    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeEmpiricalOptimisticRegret

    This module changes the adaptive empirical planner from a latest-batch summary to the sum of every transition count in the observed finite prefix. A nonnegative antitone count-radius object makes the plan's transition radius a function of the cumulative state-action visit count. The cumulative selector is measurable, so it also defines a concrete exploratory adaptive batch source.
