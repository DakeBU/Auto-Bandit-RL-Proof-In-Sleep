    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardEmpiricalOptimisticRealizedBehaviorRegret

    This module combines the concrete stochastic known-mean empirical-transition source with the global sampled-return transport. The count/optimism event and the sampled-return event retain separate confidence budgets. The expected regret of the exploratory behavior is charged explicitly against the projected recommended policy before the realized-return deviation is added.
