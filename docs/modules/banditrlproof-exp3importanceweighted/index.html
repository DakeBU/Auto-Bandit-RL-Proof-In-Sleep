    BanditRLProof.Exp3ImportanceWeighted

    This module supplies the finite-distribution algebra immediately above the deterministic Hedge theorem and below the probabilistic EXP3 process. It proves the estimator's armwise weighted-sum cancellation and exact mixed-square identity on an explicit finite action set.
