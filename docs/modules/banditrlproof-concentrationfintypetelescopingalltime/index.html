    Lean module · Probability layer

    BanditRLProof.ConcentrationFintypeTelescopingAllTime

    This module specializes the reusable finite-index/countable-time outer-measure union bound to the confidence schedule delta / ((n+1)(n+2)). Its reciprocal grows polynomially, so logarithmic confidence radii retain logarithmic time growth. The theorem only composes supplied event bounds; it is not a stochastic-process or UCB result.
