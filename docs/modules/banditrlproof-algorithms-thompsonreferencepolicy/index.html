    BanditRLProof.Algorithms.ThompsonReferencePolicy

    LML defines Thompson sampling from the posterior under a fixed reference algorithm and then transports that posterior to the actual process by an algorithm-density theorem. This module isolates the corresponding local Mathlib boundary.
