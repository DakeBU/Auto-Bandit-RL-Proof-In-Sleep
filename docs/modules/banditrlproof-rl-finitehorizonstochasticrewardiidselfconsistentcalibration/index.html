    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonStochasticRewardIIDSelfConsistentCalibration

    The half-contraction calibration uses the coarse fixed point transitionBudget = rewardBound + 2 * rewardBudget. Here the actual contraction factor q < 1 is retained and the fixed point is solved exactly, so the transition budget shrinks with q.
