    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeUCBVIClippedPlanner

    This module defines the actual recurrent planner used by the Chapter 9 route. Coordinate zero uses the all-H initial Q table and its fixed finite argmax. After observing coordinates 0,...,n, the successor planner folds those exact transition summaries, normalizes their cross-stage aggregate row, and applies the backward recurrence
