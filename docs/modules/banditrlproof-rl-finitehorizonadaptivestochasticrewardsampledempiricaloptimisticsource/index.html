    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticSource

    This module constructs a genuinely sampled-reward adaptive optimistic source. The successor table is computed from the latest complete stochastic batch, including its observed rewards, rather than from the known-mean projection.
