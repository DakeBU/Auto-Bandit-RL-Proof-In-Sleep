    Lean module · OFUL

    BanditRLProof.OFULScheduledPowerOfTwoForcedHistoryAlgorithm

    This module packages one horizon-independent deterministic history algorithm. At history indices one below a power of two it selects the arm indexed by that power's exponent; at every other index it uses the ordinary telescoping OFUL selector.
