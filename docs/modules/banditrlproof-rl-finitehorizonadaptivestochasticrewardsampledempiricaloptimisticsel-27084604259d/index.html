    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticSelfConsistentCausalRealizedSuccessorRegret

    This module combines the actual-sampled empirical-model event with the successor-only globally centered return event on the genuinely dependent round-varying source. Coordinate n + 1 is generated by the exploratory policy selected from the prefix through n and contains episodes (n + 1) complete episodes. Expected and realized successor regret are therefore weighted by the actual coordinate batch sizes and normalized by their finite sum, never by a constant-window episodes * rounds denominator.
