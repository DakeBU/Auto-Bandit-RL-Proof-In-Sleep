    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonIIDAllCoordinateFiniteBatchConfidence

    This module turns the compiled generated reward and transition laws into an actual MDP.FiniteBatchModel.Confidence producer. The construction is noncircular: reward radius is zero, transition radius is one fixed external budget, transition coordinate radii use genuine expected-count lower margins, and the recursive value envelope is the explicit linear function remaining * (rewardBound + transitionBudget).
