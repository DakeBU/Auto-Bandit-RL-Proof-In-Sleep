    Lean module · EXP3

    BanditRLProof.Exp3MixedSquarePredictableVarianceSparseLossRealizedMarkovProbabilisticSparsity

    This module allows the per-round support-cardinality contract to fail on an explicit generated-trajectory event. On paths outside that event, sparsity still supplies the sparsity * horizon loss-mass budget used by the observed mixed-square and Hedge terms. The Markov variance closure instead uses the global arms.card * horizon loss-mass envelope, so the exceptional event costs its actual generated-measure probability without assuming it is null.
