    BanditRLProof.TsallisScheduledSuboptimalExpectedBound

    This module converts the generated pathwise refined half-power budget into a deterministic expression involving square roots of expected action probabilities. It is the Jensen bridge between the compiled scheduled expected-regret theorem and the self-bounding completion-of-squares consumer.
