    BanditRLProof.OFULScheduledAllHorizonAllRoundGap

    This module adds the fixed canonical initial round to the compiled one-policy all-horizon successor-gap tail. The resulting event still uses the same telescoping-schedule policy and the same all-time confidence failure event.
