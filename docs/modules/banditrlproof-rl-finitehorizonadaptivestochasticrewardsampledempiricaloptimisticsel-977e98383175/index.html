    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticSelfConsistentCausalModelConfidence

    This module transports actual sampled count-and-reward empirical-model events to the dependent source whose coordinate t contains episodes t complete stochastic episodes. Unlike the constant-window route, local count and reward shares are functions of the coordinate. The fixed-prefix failure budget is therefore their genuine finite ENNReal sum.
