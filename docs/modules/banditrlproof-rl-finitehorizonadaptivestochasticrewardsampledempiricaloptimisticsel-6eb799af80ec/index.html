    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveStochasticRewardSampledEmpiricalOptimisticSelfConsistentCausalExplicitRate

    The causal source uses a genuinely round-varying batch size. Its regret rate therefore cannot reuse the constant-window episodes * rounds algebra. This module keeps the exact successor mass and proves that the corresponding positive-weight average of the coordinatewise scheduled rate tends to zero.
