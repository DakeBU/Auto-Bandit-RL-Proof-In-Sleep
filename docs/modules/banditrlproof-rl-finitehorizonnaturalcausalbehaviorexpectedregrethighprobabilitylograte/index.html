    BanditRLProof.RL.FiniteHorizonNaturalCausalBehaviorExpectedRegretHighProbabilityLogRate

    This module upgrades the natural-prefix pathwise process to a fixed-prefix high-probability statement on the genuine heterogeneous dependent causal source. The probability is inherited from the existing finite union of selected count-and-reward empirical-model events; no new independence, MGF, or concentration claim is introduced here.
