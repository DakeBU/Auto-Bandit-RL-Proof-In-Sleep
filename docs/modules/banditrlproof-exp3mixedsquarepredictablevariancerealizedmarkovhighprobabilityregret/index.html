    BanditRLProof.Exp3MixedSquarePredictableVarianceRealizedMarkovHighProbabilityRegret

    This module discharges the explicit predictable-variance overflow residual by Markov's inequality. The resulting theorem requires a caller-supplied lintegral bound for the cumulative predictable mixed-square variance; no such algorithm-specific expectation bound is inferred from predictability.
