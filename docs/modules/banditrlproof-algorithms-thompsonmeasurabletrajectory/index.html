    BanditRLProof.Algorithms.ThompsonMeasurableTrajectory

    The pointwise HistoryEnvironment API does not by itself say that feedback laws vary measurably with the environment. This module records that missing joint regularity and uses Mathlib's kernel-valued Ionescu-Tulcea theorem to construct the complete environment-indexed pair-trajectory kernel.
