    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonTrajectory

    This module constructs the genuine finite trajectory generated by a Markov policy. A trace with n decisions records the sampled action and resulting next state at each coordinate. The recursive trajectory kernel is then used to identify expected cumulative reward with the backward policy value.
