    Lean module · Tsallis-FTRL

    BanditRLProof.TsallisFTRLFiniteHorizonSelection

    This module applies the fixed half-Tsallis minimizer choice to cumulative loss vectors. It removes the caller-supplied minimizer certificates from the deterministic finite-horizon FTRL decomposition and records the successor indexing needed by importance-weighted updates.
