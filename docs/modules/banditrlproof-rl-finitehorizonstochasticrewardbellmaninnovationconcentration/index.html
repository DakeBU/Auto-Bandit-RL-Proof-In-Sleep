    BanditRLProof.RL.FiniteHorizonStochasticRewardBellmanInnovationConcentration

    This module controls the policy and transition randomness in the mean Bellman return r(s, a) + V(s'). Sampled reward noise is deliberately left to the separate cumulative reward-deviation theorem.
