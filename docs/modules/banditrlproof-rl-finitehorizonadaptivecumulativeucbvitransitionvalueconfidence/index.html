    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeUCBVITransitionValueConfidence

    Singleton transition coordinates do not by themselves imply a sharp bound for (P_hat - P) V* without a sqrt |State| loss. This module therefore proves the bounded scalar projection as another coordinate of the same generated transition residual family. It never introduces an offline or independent sample law.
