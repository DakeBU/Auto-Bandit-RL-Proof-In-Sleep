    BanditRLProof.RL.FiniteHorizonNaturalCausalStoppingTimeAverageRealizedBehaviorRegretAlmostSureConsistency

    This module equips the heterogeneous causal batch trajectory with its dependent Filtration.piLE natural filtration. The exact per-batch-normalized, equal-round-weighted average realized behavior-regret process is strongly adapted to that filtration: its value at prefix r uses only successor batches with coordinates at most r.
