    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonStochasticRewardIIDTotalReturnConcentration

    This module takes finite products of complete reward-bearing trajectories. Independence is only asserted across episodes. Each episode deviation remains centered by the policy value at that trajectory's own sampled initial state.
