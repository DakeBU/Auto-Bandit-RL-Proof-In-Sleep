    Lean module · Finite-horizon RL

    BanditRLProof.RL.FiniteHorizonAdaptiveCumulativeUCBVIBernsteinConfidence

    The Hoeffding producer records the exact generated visit compensator. The UCBVI-CH analysis additionally needs the Bernoulli variance of each next-state coordinate. This module proves that stronger fixed-tilt leaf from the same transition kernel. It is not an independent sample model.
