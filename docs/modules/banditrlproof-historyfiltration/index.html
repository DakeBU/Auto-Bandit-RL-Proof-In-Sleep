    BanditRLProof.HistoryFiltration

    This module gives a narrow project-local filtration canary: the sigma-algebras generated by past action/reward singleton events form a Mathlib filtration. It does not construct kernels, policies, conditional expectations, conditional MGF witnesses, or adaptive regret theorems.
