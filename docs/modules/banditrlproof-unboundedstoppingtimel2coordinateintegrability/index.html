    BanditRLProof.UnboundedStoppingTimeL2CoordinateIntegrability

    This module provides the countable-fiber transport needed when an unbounded WithTop Nat stopping time has an L2 round count and the deterministic-time coordinates have a uniform L2 bound. The argument is a measurable equality- fiber decomposition plus Holder; it is not optional stopping.
