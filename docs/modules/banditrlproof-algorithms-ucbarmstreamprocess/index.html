    Lean module · UCB

    BanditRLProof.Algorithms.UCBArmStreamProcess

    This module mirrors the deterministic part of the pinned LML array model. It recursively builds the inclusive action/reward history, uses round-robin initialization followed by the native Real history-index selector, and reads the selected arm's next unused latent reward coordinate.
