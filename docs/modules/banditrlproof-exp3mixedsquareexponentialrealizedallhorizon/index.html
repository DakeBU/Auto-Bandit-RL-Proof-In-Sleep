    Lean module · EXP3

    BanditRLProof.Exp3MixedSquareExponentialRealizedAllHorizon

    The explicit exponential-square schedule has its refined 14 * gamma * T threshold when four horizon inequalities make clipping inactive. Outside that regime this module reuses the compiled almost-sure horizon bound and the strict T + 1 zero-probability threshold. The fallback closes the active-clipping presentation without claiming a sharp short-horizon, Freedman, or EXP3.P rate.
