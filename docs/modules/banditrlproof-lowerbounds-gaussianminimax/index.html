    BanditRLProof.LowerBounds.GaussianMinimax

    This module formalizes the proof of Lattimore--Szepesvari, Theorem 15.2, on the repository's canonical finite-history law. The local history index is inclusive: lastRound represents exactly lastRound + 1 observations.

    theorem BanditRLProof.LowerBounds.finiteArmedGaussianMinimaxLowerBound Compiled
