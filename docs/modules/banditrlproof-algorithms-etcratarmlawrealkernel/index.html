    BanditRLProof.Algorithms.ETCRatArmLawRealKernel

    This module pushes the existing Rat arm laws forward along the cast to Real, identifies the resulting identity-integral kernel means and gaps, and then assembles the canonical exact per-arm ETC pull-count bounds into the LML-shaped finite sum for Real kernel regret.
