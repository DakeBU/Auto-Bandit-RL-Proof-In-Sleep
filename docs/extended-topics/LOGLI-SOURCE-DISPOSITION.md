# Log-Li: bounded recent-source disposition

Zhu and Huang, *Lipschitz Bandits in Optimal Space*, ICLR2025. Frozen PDF
SHA256: 16f77ebdf6734a93323b60726aae8921d4d9c37ec9fd08ce0cd61fc90dcdbea8.
Independent reading covered the complete model, Algorithms1-2, Lemmas1-5,
Corollary1 and both main theorem proofs on PDF pages2-9. Experiments, code,
later versions and external cited proofs were not certified.

Do not import the printed full upper/lower theorem as an accepted HOO dependency.
The independent audit confirms that bounded real magnitudes do not establish
exact bit complexity; the displayed geometric sum fails at a=2,B=3 (22>16);
and accuracy of a comparison arm does not bound all later shallow resampling.
It also records model/initialization, stopping/strict-guard, packing-scale and
lower-bound-bridge issues. These are bounded proof/model objections, not a
claim that a repaired asymptotic regret or memory rate is impossible.

The finite-state counting core of Lemma5/Corollary1 is defensible under an
explicit complete-memory-state interface. It does not itself establish the
Lipschitz lower bound, and is not used in the selected HOO proof. Likewise,
Assouad and the cited external rate/memory results remain comparison-only.

This source-selection decision preserves HOO's exact frozen substantive
endpoint and all its producers. It does not replace that endpoint with a
new Log-Li algorithm or require quantization/algorithm repair just to select
HOO. Detailed anchors, examples, supported local steps and exclusions are
hash-bound in `runs/extended-topics-20260919/logli-source-disposition.json`.
