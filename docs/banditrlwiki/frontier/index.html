    How a leaf closes

    1. Freeze the contract.Fix assumptions, regret notion, quantifiers, constants, and source location.
    2. Audit primary evidence.Record the closest compatible upper and lower theorem; name every mismatch.
    3. Compile the exact bridge.Close one named proof obligation without adding an unadvertised assumption.
    4. Pass independent gates.Lean, tests, website links, source review, and deployment evidence must agree before status promotion.
