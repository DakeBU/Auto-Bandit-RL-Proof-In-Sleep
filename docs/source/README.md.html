    1 # BanditRLlib — anonymous review snapshot
2 
3 This frozen appendix accompanies **ABRL: A Target-Faithful Autoformalization
4 Harness and Lean 4 Library for Bandit and Reinforcement Learning Theory**.
5 
6 The release contains the complete Lean library and tests from a verified
7 snapshot, the declaration dependency exporter, and a reproducible anonymous
8 reading website. The prebuilt website is in `docs/index.html`.
9 
10 [Open the reading website](docs/index.html).

12 ## Read and check
13 
14 Download the anonymous archive and install [Lean through Elan](https://lean-lang.org/install/).
15 The toolchain and Mathlib dependency are pinned in the checked-in configuration.
16 
17 ```sh
18 lake exe cache get
19 lake build
20 lake build Tests
21 python3 website/scripts/build_site.py --lean-verified
22 python3 website/scripts/check_site.py
23 python3 -m http.server 8000 --directory docs
24 ```
25 
26 Open `http://localhost:8000/` for chapters, exact declarations, and the Lean graph.
27 The site is static: it is not an online compiler or submission service.
28 Compiled labels come from the unchanged, CI-verified Lean snapshot. The build
29 flag verifies file integrity, not Lean execution; the two Lake commands above
30 perform independent proof checking. Partial/planned results remain labelled.
31 
32 ## Scope and development policy
33 
34 This is a **frozen review branch**, not a development branch. All subsequent
35 library development belongs on **main**. Do not merge this review branch into
36 main, and do not automatically mirror later main commits into this snapshot.
37 An explicit, separately checked release is required if reviewers need an update.
38 
39 Author records, contributor cards, operational logs, original repository links,
40 and original Git history are excluded. Required third-party licensing is retained
41 in [NOTICE.md](NOTICE.md). Bibliographic references identify mathematical sources,
42 not project contributors. The website graph is a teaching/import/declaration map;
43 it must not be mistaken for the separately frozen proof-body analysis in the paper.
44 
45 Only share the anonymization service link with reviewers. A branch URL on the
46 original GitHub host is **not anonymous**, even when its file contents are.
