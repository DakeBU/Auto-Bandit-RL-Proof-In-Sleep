4 /-!
5 # Native Real ETC finite-prefix law transport
6 
7 This module factors the native Real ETC commit, action, and finite-horizon
8 kernel regret through the finite exploration reward prefix. It then transports
9 the canonical infinite-product regret bound to an arbitrary probability space
10 from equality of that finite-prefix pushforward law. A final adapter permits
11 an external action process that agrees almost surely with the local ETC action.
12 -/

25 /-- Extend a finite exploration prefix by zero outside the exploration phase. -/
26 def realRewardTraceOfExplorationPrefix {K : Nat} (spec : ETC.Spec K)
27     (rewardPrefix : Fin (spec.explorationPulls * K) -> Real) : RewardTrace Real :=
28   fun t => if ht : t < spec.explorationPulls * K then rewardPrefix ⟨t, ht⟩ else 0
