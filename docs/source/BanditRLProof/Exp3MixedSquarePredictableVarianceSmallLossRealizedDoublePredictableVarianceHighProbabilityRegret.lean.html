5 # Small-loss EXP3 regret with two predictable-variance budgets
6 
7 The predictable-regret component uses the armwise loss-mass budget and the
8 mixed-square predictable variance. The realized-minus-predictable component
9 uses its exact selected-loss predictable variance. An explicit bad set is
10 retained so probabilistic sparsity can discharge both pathwise budgets without
11 charging the same failure event more than once.
12 -/
