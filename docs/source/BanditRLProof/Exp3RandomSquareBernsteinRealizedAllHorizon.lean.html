5 # All-horizon random-square realized EXP3 route
6 
7 The explicit random-square schedule has its refined threshold when two
8 large-horizon inequalities make clipping inactive.  Outside that regime this
9 module reuses the compiled almost-sure horizon bound and a strict `T + 1`
10 threshold.  The result covers every positive horizon without asserting cubic
11 or quadratic dominance on the active-clipping branch.
12 -/

20 /-- The regime in which the explicit random-square exploration schedule
21 satisfies both confidence dominance contracts without activating its clip. -/
22 def randomSquareBernsteinLargeHorizonCondition
23     (K T delta : Real) : Prop :=
24   8 * (K * Real.log (4 / delta)) <= T ∧
25     8 * ((Concentration.intervalVarianceProxy 0 1 : NNReal) : Real) *
26       Real.log (4 / delta) <= T
27 
28 /-- All-horizon threshold for the random-square route: use the explicit
29 large-horizon rate in its valid regime and `T + 1` otherwise. -/
30 noncomputable def randomSquareBernsteinAllHorizonRegretThreshold
31     {Action : Type v} (arms : Finset Action) (horizon : Nat)
32     (delta : Real) : Real := by
33   classical
34   let gamma := randomSquareBernsteinClippedExplorationRate
35     (arms.card : Real) (horizon : Real) delta
36   exact if randomSquareBernsteinLargeHorizonCondition
37       (arms.card : Real) (horizon : Real) delta then
38     randomSquareBernsteinRealizedExplicitThreshold arms gamma horizon delta
39   else
40     (horizon : Real) + 1
