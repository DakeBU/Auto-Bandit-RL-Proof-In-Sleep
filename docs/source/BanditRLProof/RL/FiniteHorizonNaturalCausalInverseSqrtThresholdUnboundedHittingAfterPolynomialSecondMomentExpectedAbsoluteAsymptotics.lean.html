5 # Degree-eight asymptotics for the uncapped inverse-sqrt hitting time
6 
7 This module transports the explicit polynomial moment envelope to the actual
8 stopping-round second moment and stopped-regret expected absolute value. All
9 model and source parameters are fixed while the threshold index varies.

12 uniform integrability, L1 convergence, or an optional-stopping identity.
