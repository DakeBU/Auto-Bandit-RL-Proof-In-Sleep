5 # Expected truncation replacement for stopped behavior and return coordinates
6 
7 This module transports the accepted componentwise `L1` truncation theorem
8 through the Bochner integral. It compares capped and genuine uncapped
9 successor-policy value gaps and return deviations on the same generated
10 trajectory law, and preserves the exact expected realized-regret
11 decomposition. It does not exchange expectation with a stopping index.
