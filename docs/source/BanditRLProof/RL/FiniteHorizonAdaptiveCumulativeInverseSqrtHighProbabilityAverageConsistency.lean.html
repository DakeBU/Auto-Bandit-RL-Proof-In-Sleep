3 /-!
4 # Vanishing-delta high-probability average consistency
5 
6 This module specializes the scheduled average recommendation-regret route to
7 the confidence budget `delta_n = 1 / (n + 2)`.  Both the failure budget and
8 the deterministic average-regret certificate tend to zero.
9 
10 The source-level statements remain a dependent family of finite-window
11 certificates.  The scheduled episode count, and hence the trajectory sample
12 space, changes with `n`; no fixed-process convergence-in-probability claim is
13 made here.
14 -/

32 /-- The confidence budget used at finite window `n`. -/
33 noncomputable def vanishingAverageConfidenceDelta (n : Nat) : Real :=
34   1 / ((n + 2 : Nat) : Real)
35 
36 /-- The scheduled batch size at finite window `n`, with `n + 1` rounds. -/
37 noncomputable def vanishingDeltaScheduledEpisodes
38     (mdp : MDP State Action) (n : Nat) (visitFloor : Real) : Nat :=
39   normalizedCumulativeInverseSqrtScheduledEpisodes mdp (n + 1)
40     (vanishingAverageConfidenceDelta n) visitFloor

182 At one finite window, the average-regret violation set is contained in the
183 measurable simultaneous count bad event and inherits its vanishing confidence

185 violation set itself.  Outside the measurable bad event, optimism and the
186 explicit average certificate both hold.
187 -/
