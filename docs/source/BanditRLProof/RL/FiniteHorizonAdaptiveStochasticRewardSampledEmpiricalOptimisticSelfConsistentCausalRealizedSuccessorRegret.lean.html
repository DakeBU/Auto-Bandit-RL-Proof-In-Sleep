5 /-!
6 # Realized successor regret on the heterogeneous causal source
7 
8 This module combines the actual-sampled empirical-model event with the
9 successor-only globally centered return event on the genuinely dependent
10 round-varying source.  Coordinate `n + 1` is generated by the exploratory
11 policy selected from the prefix through `n` and contains `episodes (n + 1)`
12 complete episodes.  Expected and realized successor regret are therefore
13 weighted by the actual coordinate batch sizes and normalized by their finite
14 sum, never by a constant-window `episodes * rounds` denominator.
15 
16 The proof route first establishes the exact weighted identity
17 
18 `realized = expected - globally centered deviation`.
19 
20 Outside the model event, each sampled model at coordinate `n` supplies
21 optimism and recommended-policy expected-regret control.  The exploratory
22 policy that generates coordinate `n + 1` pays the existing explicit
23 exploration charge.  A finite event union with the compiled heterogeneous
24 return tail then yields realized successor-average behavior regret.
25 
26 Regularity is finite measurable nonempty State/Action with measurable
27 singletons, a probability initial law, Standard Borel State/Action, positive
28 scheduled batch sizes, a positive selected-reward sub-Gaussian proxy, bounded
29 stored means, path support, and a positive horizon/base visit floor.
30 
31 Failure policy: preserve the actual sampled batches, `n`-prefix to `n + 1`
32 policy indexing, coordinate-specific episode weights, global initial-law
33 centering, and the exact finite model plus return failure budget.  This is a
34 fixed-prefix causal theorem; it proves no old constant-window rate,
35 uniform-time, pathwise, almost-sure, anytime, minimax, reachability, or
36 complete-UCB-VI claim.
37 -/

204             AdaptiveStochasticEpisodeBatchSource.optimalInitialExpectedReturn
205               mdp initialState -

207             (episodes ((round : Nat) + 1))
208             (trajectory ((round : Nat) + 1)))) =
209         ∑ round : Fin rounds,

211               (source.successorPolicyAt trajectory round).expectedRegret
212                 initialState -
213             source.successorGlobalReturnIncrement
214               ((round : Nat) + 1) trajectory) := by
215       apply Finset.sum_congr rfl
216       intro round _hround
217       rw [source.successorGlobalReturnIncrement_succ_eq]
218       unfold MarkovPolicy.expectedRegret
219         AdaptiveStochasticEpisodeBatchSource.optimalInitialExpectedReturn
220       rw [(source.successorPolicyAt trajectory round).integral_cumulativeReward_trajectoryMeasure_eq_integral_valueAt_zero]
221       ring
222     _ = (∑ round : Fin rounds,
223             (episodes ((round : Nat) + 1) : Real) *
224               (source.successorPolicyAt trajectory round).expectedRegret
225                 initialState) -
226           ∑ round : Fin rounds,
227             source.successorGlobalReturnIncrement
228               ((round : Nat) + 1) trajectory := by
229       rw [Finset.sum_sub_distrib]
