3 /-!
4 # Stage-resolved Bellman innovation for UCBVI-CH
5 
6 This file proves the within-episode martingale bound for an arbitrary fixed
7 chronological table of continuation gaps in `[0,H]`.  The proof recurses
8 through the actual policy trajectory kernel one transition at a time, so its
9 variance budget is `H * H^2 / 4`, rather than the invalid whole-episode
10 range-square budget `H^4 / 4`.
11 -/

29 /-- Chronological Bellman innovation for a deterministic action table.  The
30 sampled action coordinate is deliberately ignored: the table chooses the
31 action from the recursively reconstructed current state.  This makes the
32 pathwise recursion canonical on every batch, while its law is still the exact
33 generated deterministic-policy trajectory law. -/
34 noncomputable def sampledCumulativeDeterministicGapInnovationFrom
35     (mdp : MDP State Action) (table : DeterministicMarkovPolicyTable mdp)
36     (feature : Fin mdp.horizon -> State -> Real) :
37     (remaining : Nat) -> remaining <= mdp.horizon -> State ->
38       StepTrace Action State remaining -> Real
39   | 0, _, _, _ => 0
40   | remaining + 1, hremaining, state, trace =>
41       let stage : Fin mdp.horizon :=
42         ⟨mdp.horizon - (remaining + 1), by omega⟩
43       mdp.transitionValue (feature stage) state (table stage state) -
44           feature stage (trace 0).2 +
45         sampledCumulativeDeterministicGapInnovationFrom mdp table feature
46           remaining (by omega) (trace 0).2 (Fin.tail trace)
