4 # History-adaptive predictable losses on IID states
5 
6 The loss chosen at a successor round may inspect the complete pre-action pair
7 history.  It may inspect the fresh IID state only through the current state
8 coordinate.  This coordinate-locality contract is exactly what is needed for
9 the canonical visible trajectory to factor through every finite state prefix.
10 -/

19 /-- A predictable loss family reads state coordinate `0` initially and state
20 coordinate `n + 1` after a history of length `n + 1`.  The successor value may
21 otherwise depend arbitrarily and measurably on that pre-action history. -/
22 structure HasIIDStateCoordinateLocality
23     {LossState : Type u} {Action : Type v}
24     [MeasurableSpace LossState] [MeasurableSpace Action]
25     (loss : Exp3.PredictableLossVector (Nat -> LossState) Action) : Prop where
26   initial_congr : forall environment1 environment2 action,
27     environment1 0 = environment2 0 ->
28       loss.initial environment1 action = loss.initial environment2 action
29   successor_congr : forall n environment1 environment2 history action,
30     environment1 (n + 1) = environment2 (n + 1) ->
31       loss.successor n environment1 history action =
32         loss.successor n environment2 history action
