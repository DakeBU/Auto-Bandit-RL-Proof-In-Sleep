Pick: Candidate A, but use the if-zeroed univ-sum shape.

Do not start the filtered Finset.filter version first. The lower-risk leaf is
the analytically equivalent non-best wrapper:

```lean
(Finset.univ : Finset (Fin K)).sum
  (fun a => if a = model.bestArm then 0 else tail a)
```

This avoids filter algebra while still making the best-arm contribution zero.
A true filtered-sum theorem can be a follow-on leaf using Finset.sum_filter.

Exact Lean-facing statement:

```lean
theorem ETC.prob_commitArm_ne_bestArm_le_sum_nonbest_pairwise_tail
    {Omega : Type u} {K : Nat}
    [MeasurableSpace Omega]
    (mu : Measure Omega)
    (model : FiniteBanditModel K)
    (commitArm : Omega -> Fin K)
    (empMean : Omega -> Fin K -> Rat)
    (tail : Fin K -> ENNReal)
    (hcommit_argmax :
      forall omega : Omega, forall a : Fin K,
        empMean omega a <= empMean omega (commitArm omega))
    (hpair_tail :
      forall a : Fin K, (a = model.bestArm -> False) ->
        mu {omega : Omega |
          empMean omega a >= empMean omega model.bestArm} <= tail a) :
    mu {omega : Omega | commitArm omega = model.bestArm -> False} <=
    (Finset.univ : Finset (Fin K)).sum
      (fun a : Fin K => if a = model.bestArm then 0 else tail a)
```

1. Start from the compiled guarded-event sum wrapper.
2. Use `Finset.sum_le_sum`.
3. For `a = model.bestArm`, prove the guarded event is empty and close against

4. For `a != model.bestArm`, erase the guard by measure monotonicity and apply
