## Literal model FC-WO-reset-v1
K >= 2 bounded [0,1] reward means. An arm is selected classically at a block boundary using classical history. Each block acts on a fresh initialized finite-dimensional register, queries only the selected arm's unknown unitary U_i and/or its matching dagger a total q <= D times, intersperses known unitaries, measures at the end, and discards the whole quantum register. No cross-block quantum memory, coherent arm-index access, intermediate measurement or classical adaptation inside a block. Every U_i and U_i-dagger query consumes one horizon unit and charges gap_i to pseudo-regret, including inverse queries, unsuccessful estimates and final exploitation. Shots count blocks, never individual queries. Query depth is sequential unknown-oracle calls within a block, not physical circuit depth. Gate count, physical depth, synthesis, state loading and wall-clock are separate resource fields. Known reflections require an explicit implementation/cost; no reflection about an unknown state or unknown-mean angle is supplied free.

B uses fixed actual implemented circuit and matching inverse for each arm/fidelity; its systematic mean bias is bounded relative to the target. Per-invocation drifting noise is a distinct unimplemented model. Statistical radii may be conditional on past history; no unbiased, independent, or sub-Gaussian estimate assumption follows from a confidence interval alone.

## First anchor: normalized Born stability
For a complex Hilbert space, a unit vector psi, unitary continuous linear operators U,V, and an effect P satisfying 0 <= P <= I in the operator Loewner order, define p(U) = Re <U psi, P(U psi)>.
If ||U-V||op <= eta, then |p(U)-p(V)| <= 2 eta. Both U and V must be unitary; omitting normalization or the approximate unitary condition can invalidate the statement. Binder classification: spaces/types TYPING; norm psi=1, U/V unitary, effect positivity/upper bound, distance premise SOURCE (user-requested abstract stability statement). Effect norm <=1 and output-state normalization are RULED dependency edges, not extra public hypotheses. Inner product conjugate-linear in first slot. No tensor reordering or global-phase quotient is introduced. Definition is literal.
Proof topology fixed before implementation: split quadratic form difference into two inner products -> Cauchy-Schwarz -> effect contraction (derived from Loewner effect assumptions) -> unitary norm preservation -> operator-distance application bound -> 2 eta. This is not amplitude estimation.

# Statement Seal v1 finite-dimensional implementation refinement
The first Born anchor is implemented on arbitrary finite complex Euclidean spaces using Mathlib MatrixOrder (Loewner order) and the L2 operator norm. This is a named finite-dimensional specialization of the generic Hilbert-space target, not claimed as infinite-dimensional closure. The effect contraction is derived from 0<=P<=I via Mathlib CStarAlgebra; it will not be introduced as a public source hypothesis.
