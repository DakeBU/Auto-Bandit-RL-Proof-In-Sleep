# Single-block query-word seal v1
Finite complex Euclidean basis, chronological list of either known unitary gates (each independently specified) or forward/inverse calls to one fixed arm oracle U. Oracle call count counts both directions; known instructions count separately. Fresh normalized input psi, final effect P with 0<=P<=I. For a second unitary V with operator distance<=eta and same known instructions, prove ||eval(word,U)-eval(word,V)|| <= queries(word)*eta by telescoping; dagger norm difference uses star isometry. Every eval is unitary from word induction, a dependency edge. Then Born bias <=2*queries*eta via BornStability. A bounded block has queries<=D. This is an exact-real operator/query circuit semantics theorem, not an estimator or quantum reset stochastic-process construction, not finite-bit synthesis. User's full block protocol further requires initialized state, end measurement/discard and only classical history across blocks: those producers remain open.
