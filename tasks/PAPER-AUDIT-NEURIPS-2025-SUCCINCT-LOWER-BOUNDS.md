## Hidden regularity decision

The source only assumes that the atom set is nonempty, unit norm, and closed
under negation.  Those hypotheses do not imply that it spans the ambient
inner-product space.  If a nonzero vector is orthogonal to all atoms, then its
`Q` value is zero and arbitrary multiples remain `Q <= 1`; the corresponding
`R` supremum is unbounded.  Lean therefore proves Lemma 3.2 only where the
source vector itself is succinct and the relevant supremum is explicitly
bounded.  A global norm/dual-norm interface requires one of:

- a spanning/nondegeneracy hypothesis;
- an extended-real codomain for `R`; or
- restriction to the span/quotient generated by the atoms.

No such repair is silently inserted into Theorem 3.8.

## Nonclaims

This task does not compile Lemmas 3.3--3.6, Assumption 3.7, Theorem 3.8, any
