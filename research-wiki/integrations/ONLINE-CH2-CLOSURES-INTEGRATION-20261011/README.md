# Convexity closure integration

This bounded packet adds two modules and two canaries to the existing BanditRLProof library. Twelve retained declarations (eleven theorems and the literal `upperAdd` definition) support four convexity constructions: affine precomposition, indexed suprema, real monotone composition and nonnegative combinations. One reader and four highlights expose these endpoints in the shared Online Learning Book. These are four source statements, not eleven numbered source theorems or a completed chapter.

The primary source is Orabona, *Online Learning: A Modern Introduction Using Convex Optimization*, arXiv:1912.13213v10, four unnumbered bullets on printed p.10 / PDF p.22; the next page leaves all four proofs as exercises. Its PDF SHA256 is `cef4edfa97a6e063e53e9c532717c50aa156e5bc782ea49f969b3385011a1b17`. The separately adopted mixed-addition convention comes from Rockafellar, *Conjugate Duality and Optimization*, printed p.6 / PDF p.17, PDF SHA256 `29d57ab07857b8270c175343746c77b4138f2db6161ae20174a0bba076991b0e`.

## Source boundary and library proofs

Real modules generalize the source's Euclidean spaces. The affine map acts on the input and need not be injective. Supremum uses any index type, including an empty family under the explicit complete-lattice convention that its supremum is negative infinity. Monotone composition keeps both functions globally real-valued and the outer function globally nondecreasing.

The named upper addition `upperAdd a b = -(-a + -b)` agrees with real addition on finite inputs and makes positive infinity dominate mixed infinities. This is a separately attributed interpretation of Orabona's unspecified arithmetic, not ordinary Mathlib EReal addition. Zero times either infinity equals zero is a further explicit library convention; the selected Rockafellar paragraph does not establish that zero-scaling rule. Improper functions, empty domains and zero weights remain allowed.

The library proves affine closure by pulling back the real-height epigraph, supremum closure by intersecting epigraphs, and monotone composition by two real convexity inequalities joined by monotonicity. For upper sums, a finite-height witness equivalence reduces the argument to real upper bounds. Zero scaling gives the zero function; positive scaling divides the epigraph height. The final weighted combination composes these results. The source-only inventory retains the omitted author proofs: none of these implementation routes is attributed to a printed author derivation. The spike canary exhibits the failure of convexity for ordinary bottom-dominant EReal sums.
