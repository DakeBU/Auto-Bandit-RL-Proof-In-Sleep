# Code of Conduct

This community is for rigorous, constructive collaboration across mathematics,
machine learning, and formal methods.

Participants must be respectful, explain technical objections with evidence,
credit prior work accurately, welcome learners, and distinguish mistakes from
misconduct. Harassment, discrimination, personal attacks, intimidation,
plagiarism, deliberate misrepresentation of proof status, and publication of
private information are not acceptable.

Maintainers may pause unproductive discussion, request a more precise technical
statement, hide harmful content, or restrict participation. Report conduct or
privacy concerns privately through the repository owner's GitHub profile; do
not put sensitive personal information in a public issue.

Good-faith technical disagreement is welcome. The standard is a clear,
evidence-based, and humane review process.
