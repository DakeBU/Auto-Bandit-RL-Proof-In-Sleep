## Anti-anchored boundary checks

Inside V, the sum is f(x)+0=f(x), so the primary iff genuinely preserves the original value. Outside V, ordinary addition gives top if f(x) is not bottom, and bottom if it is bottom. Neither is an embedded real. Thus noBottom is unnecessary for the finite-witness iff; adding it would narrow the source-refinement interface unnecessarily. Membership alone is insufficient: f≡top and x∈V is a direct counterexample. The iff does not assert equality of arbitrarily chosen existential witnesses, although the inside sum does equal f(x).

Below-top domain is different: bottom is included. On a one-point carrier with V empty and f≡bottom, ordinary bottom+top=bottom makes the sum domain whole while domain f intersect V is empty. Hence removing hbot invalidates the second header. Global noBottom is sufficient (not a claim of weakest possible condition); it could be weakened to avoiding bottom outside V in a different helper, but the explicit stronger supporting interface is not a narrowing of the primary source necessary direction. The second header should remain labeled a separate library refinement.

No convexity, topology, closedness, nonemptiness, dimension or properness is needed for this algebra. The arbitrary-carrier scope generalizes source Euclidean x. No upperAdd substitution is permitted: it would change the mixed-infinity case and render the current noBottom boundary analysis inapplicable.
