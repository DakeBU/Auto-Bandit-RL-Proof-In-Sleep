    Reader checkpoint

    Notation you will meet

    True global support and finite values
    Proper f never takes minus infinity and has a finite ambient witness. g in partial f(x) tests every ambient y. Properness plus that actual support prove f(x) is finite before toReal differences.
    Actual current-only choice
    G(f,x) chooses one support from the true nonempty global support set, otherwise zero. Source-valid feasible queries use the nonempty branch. It is a noncomputable whole-function choice, not an executable oracle or every possible adaptive tie rule.
    Round and endpoint indices
    Lean X0=x1, Xt is the output before loss(t), and X(t+1) is its projected update. At horizon T, last played eta is eta(T-1), terminal is X(T). Initialization and learning-rate schedule are externally prescribed.
    source algorithm · ordered flow

    Output, observe, support, project

    Read top to bottom: each step supplies the state or proof fact used by the next one.

    1. 01
      Output the feasible current point

      Start from the prescribed x1 in V. Projection membership proves every later output feasible. Strict-prefix induction compares equal past losses and schedules, so current/future loss changes do not change the current point.

    2. 02
      Observe the current loss and choose its support

      Subdifferentiability on V gives a true global support at the actual feasible query. The canonical current-only selector is proved to belong to that set; no desired step inequality is supplied.

    3. 03
      Project the genuine update

      Use the shared nearest-point projection on Xt-eta(t)gt. Its existing projection theorem and support inequality produce the full Lemma2.31 chain, then divide by the positive current eta.
