    Learning goals

    • Keep finite function values before taking real differences.
    • Derive bounds for every interior global support from actual Lipschitz inequalities.
    • Construct supports from proper convexity to prove the converse.

    proof flow · ordered flow

    Prove both implications on the actual domain interior

    Read top to bottom: each step supplies the state or proof fact used by the next one.

    1. 01
      Restrict the actual pair bound to a ball

      Every interior query has a positive-radius ambient ball in U. The pair bound and finite values hold on that actual ball, so the existing normalized-support perturbation proves the bound for every g.

    2. 02
      Construct supports at both pair points

      Proper convexity and interior membership give actual global supports gx,gy via the accepted interior-existence theorem, not an extra support-existence assumption.

    3. 03
      Use finite conversion and both signs

      Convert their supporting inequalities at finite x,y to real inequalities. Cauchy-Schwarz and the uniform norm bound control f(x)-f(y) and f(y)-f(x), giving the full absolute difference.

    Proof bridge · source to Lean

    Actual supports and two signs establish the full iff

    Forward obtain an actual positive-radius ball in U and restrict genuine finite values/all-pairs bounds; shared norm-ball proof perturbs along the normalized given support. Reverse construct actual global supports at BOTH x and y from proper convexity and interior membership, certify finite EReal conversion, apply both global support inequalities and Cauchy-Schwarz/two signs to obtain the same-L absolute bound. No assumed norm conclusion or support-existence oracle.

    1. 01
      Finite values prevent an infinity projection shortcut

      At an interior point properness excludes bottom and domain membership excludes top, yielding f(x)=coe(toReal f(x)). SourceLipschitzOn separately requires actual finite witnesses on its set.
