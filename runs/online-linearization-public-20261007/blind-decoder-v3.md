## Common semantic context and notation

Work in the supplied finite-dimensional real inner-product space E, with its normed additive group structure. Domain V has a nonempty closed convex carrier, written V below. No boundedness is included. The type-level assumptions are retained as supplied; no stronger completeness, boundedness, or finite-loss assumption is silently added.

For f:E->extended reals, properness means f(x) is never minus infinity for ANY ambient x and there exists an ambient x and a real r with f(x)=embed(r). Write
\[
S(f,x)=\{g\in E:\ \forall v\in E,\ f(x)+\operatorname{embed}(\langle g,v-x\rangle)\le f(v)\}.
\]
These are GLOBAL supports, with comparisons over every v in E, not just feasible points or an interior. Let R_V(f) mean properness and nonemptiness of S(f,x) for every x in V. Properness alone allows positive infinity elsewhere. Properness plus a support at x forces actual finiteness at x: its finite ambient witness excludes positive infinity, while properness excludes negative infinity. R_V(f) therefore yields finiteness at feasible points. This is crucial because EReal.toReal is totalized and cannot unconditionally be treated as faithful real evaluation. Write f(x)^r=(f(x)).toReal; finite-value hypotheses are explicitly identified below.

A learner has type
\[
A:(t:\mathbb N)\to(\operatorname{Fin}(t)\to E)\to E.
\]
It sees only the strict past vector history as explicit data. Feasible(V,A) means \(\forall t,\forall h:\operatorname{Fin}(t)\to E,\ A(t,h)\in V\), including arbitrary off-path vector histories. This is stronger than requiring only one run's outputs feasible.

For a vector history h:Fin(t)->E, define the reconstructed output history
\[
O_A(h)(i)=A(i,h|_{<i}),\qquad i\in\operatorname{Fin}(t+1).
\]
The restriction uses exactly the first i vectors of h, so in particular the last entry uses all t past vectors. No current vector is included in A's time-t input.

A support policy p takes time t, exactly t past WHOLE loss functions F_<t, the length t+1 reconstructed output history, and the current WHOLE function f_t. Its output is a vector. Finite history length does not mean finite-query function access or executable evaluation. For fixed A,f,p, the literal recursion is
\[
h_0=\varnothing,\quad x_t=A(t,h_t),\quad
 g_t=p(t,f_{<t},O_A(h_t),f_t),\quad
 h_{t+1}=\operatorname{snoc}(h_t,g_t).
\]
Here h_t is a history of selected vectors, not output points. O_A(h_t) reconstructs the output points from that actual vector history. The current output is made before the current support is appended. There is no separate external initial-point argument: \(x_0=A(0,\varnothing)\), determined by the fixed learner. There is no comparator input to A or p and no explicit future loss input. External construction of A or p may encode other data; the interface proves no stochastic independence or nonanticipation of externally chosen parameters. There is no probability, filtration, measurability, finite-query implementation, schedule tuning, or anytime rate assertion.

Played legality is \(L_T(A,f,p):\forall t<T,\ g_t\in S(f_t,x_t)\). The optional off-path law is
\[
\operatorname{Law}_V(p):\ \forall t,F,H,f,\quad
 R_V(f)\land H(t)\in V\Longrightarrow p(t,F,H,f)\in S(f,H(t)).
\]
The histories F and H in this law need not be generated by A or mutually consistent; older output entries need not be feasible. Only current regularity and last-point feasibility are premises. Default ignores past loss functions and older outputs and uses the canonical noncomputable choice from the current global support set, else zero. It is not an arbitrary support policy nor an executable tie-breaking prescription.

For any entire vector sequence g:N->E define
\[
x_t^{\rm lin}(A,g)=A(t,(g_0,\ldots,g_{t-1})),\qquad
\ell_g(x)=\langle g,x\rangle.
\]
The comparator functional is a difference of two real sums:
\[
C_T(A,g,u)=\sum_{t=0}^{T-1}\ell_{g_t}(x_t^{\rm lin}(A,g))
             -\sum_{t=0}^{T-1}\ell_{g_t}(u).
\]
The nonlinear real-valued expression is
\[
R_T(A,f,p,u)=\sum_{t=0}^{T-1}\bigl(f_t(x_t)^r-f_t(u)^r\bigr).
\]
These definitions alone impose no regret-performance assumptions. All ranges are literal zero-based Finset.range T. The seven slots below are objects; quantifiers/information scope; hypotheses; operation; natural-language/LaTeX conclusion; constants/indices; boundaries/limits.
