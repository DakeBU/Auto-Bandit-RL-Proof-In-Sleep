     We can immediately observe a few things.

• The terms ∥g t ∥22 are due to the fact that we output xt before knowing the loss ℓt . Indeed,
  these terms become non-positive if we were allowed to observe ℓt before producing xt ,

• The last term in both bounds is non-positive, so it is usually discarded. Yet, some advanced
  proofs require it, so it is good to be aware of it.
• If we want to use time-varying learning rates, we need to control the terms ∥xt − u∥22 . To
  do it, we assume a bounded domain V . However, this assumption is false in most of the

  with an unbounded domain, as we will see in Chapter 3.
• Another important observation is that the regret bound helps us choose the learning rates
  ηt . Indeed, it is the only guideline we have. Any other choice that is not justified by a
  regret analysis is not justified at all.

                              2.2 Online Subgradient Descent
In the previous section, we introduced Projected Online Gradient Descent. However, the
differentiability assumption for the ℓt is quite strong. What happens when the losses are
convex but not differentiable? For example, ℓt (x) = |x−10|. Note that this situation is more
common than one would think. For example, the hinge loss, ℓt (x) = max(1−yt ⟨z t , x⟩, 0),
is not differentiable. It turns out that we can just use OGD, substituting subgradients for the
gradients. For this, we need some more convex analysis.


                         2.2.1 Convex Analysis Bits: Subgradients

Definition 2.16 A function f : Rd → [−∞, +∞] is closed iff {x : f (x) ≤ α} is closed
