EReal is the extended real order with bottom negative infinity and top positive infinity.
abbrev E := EuclideanSpace ℝ (Fin 1)
def coordinates : E ≃ₗ[ℝ] EuclideanSpace ℝ (Fin 1) := LinearEquiv.refl ℝ E
def point (t : ℝ) : E := EuclideanSpace.single 0 t
def quadratic (x : E) : EReal := if 0 ≤ x 0 then (((x 0 - 2) ^ 2 / 2 : ℝ) : EReal) else ⊤
def affine (x : E) : EReal := (x 0 : EReal)
EuclideanSpace ℝ (Fin 1) is the one-dimensional real coordinate inner-product space with Euclidean norm. EuclideanSpace.single 0 t has value t at its sole coordinate. LinearEquiv.refl is the identity algebraic linear equivalence.
effectiveDomain f = {x | f x < ⊤}; bottom is included.
IsMinOn f V p means ∀ q ∈ V, f p ≤ f q; membership p∈V is separate.
SourceProper f means (∀ x, f x ≠ ⊥) ∧ ∃ x, ∃ r : ℝ, f x = (r : EReal).
SourceClosed f means for every real r the set {x | f x ≤ (r : EReal)} is closed.
SourceSubdifferential f x is {g | ∀ y, f x + ((inner ℝ g (y-x) : ℝ) : EReal) ≤ f y}.
ExistsUnique means exactly one element satisfies the predicate; all arithmetic in EReal is ordinary extended-real arithmetic. Set.univ contains every point. A norm and scalar multiplication use the specified Euclidean space.
