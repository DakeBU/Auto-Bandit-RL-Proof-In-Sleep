2. **Fixed endpoints.** regret_fixed quantifies all natural T, positive constant eta, every feasible comparator, and valid losses only t<T. It preserves initial squared distance/(2eta), eta/2 times actual selected-support energy, and minus terminal squared distance/(2eta). No bounded-domain assumption is present, agreeing with printed14's explicit unbounded-domain observation. T0 extends source notation harmlessly: empty regret/energy and identical initial/terminal states cancel. regret_fixed_coarse is a separate consequence dropping the nonnegative subtracted term, not a replacement for the residual endpoint.
3. **Variable endpoints and actual diameter.** Both variable forms require T>0, positivity for every played eta, and nonincreasing adjacent played steps. No future eta is constrained. Source eta_T becomes Lean eta(T-1), and source x_(T+1) becomes iterate(T); both endpoint denominators and the negative residual are correct. The generic D is an all-pairs upper bound, not necessarily the exact diameter; nonempty V forces D>=0 and permits D0. The wrapper uses actual Bornology.IsBounded. Inspected dist_le_diam_of_mem and isBounded_iff_ediam_ne_top justify its intended bounded-set meaning. This is the finite-diameter source branch, not an unbounded-domain variable-step theorem.
4. **Tuning and comparator quantifiers.** Both tuned headers use eta=D/(G sqrt T) with strictly positive T,D,G, and conclude D*G*sqrt T. Every support premise and every regret occurrence refer to exactly that eta-dependent trajectory. regret_tuned_distance only needs initial distance to one comparator <=D, a disclosed strengthening of the bounded-diameter route; choosing a different D changes the run. regret_tuned fixes the constants and run before quantifying all feasible u, with one uniform all-pairs bound, so it does not retune per comparator. Tuning is known-horizon and conditional on supplied bounds, not anytime or hindsight minimization of the actual future gradient sum.
5. **Support-norm information and boundaries.** hgrad explicitly bounds the actual chosen support on the actual tuned trajectory. It neither demands nor derives a bound on every support at every boundary point. Closed-V Lipschitzness alone is never substituted for this premise; Theorem2.30 concerns ambient domain interior. An indicator can be constant on its feasible set while possessing unbounded boundary normal supports, so such a shortcut would be invalid. No shortcut occurs in these headers. The bound is still an assumption to establish in an application, not a constructive method for choosing G or a guarantee for arbitrary external bounds.
