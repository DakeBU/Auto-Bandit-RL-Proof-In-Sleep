    Orientation

    Who should read this. Readers beginning Orabona Chapter 1; all declarations share the canonical Lean graph.

    Learning goals

    • Distinguish the actual past-only prediction from a hindsight leader.
    • Derive the logarithmic regret bound from actual mean updates.
    • Distinguish arbitrary deterministic loss sequences from IID expectation guarantees.

    Follow-the-Leader for squared guessing loss

    Read top to bottom: each step supplies the state or proof fact used by the next one.

    1. 01
      Initialize

      Predict one half before seeing the first target.

    2. 02
      Predict

      On later rounds, output the average of all previous targets.

    3. 03
      Observe

      Pay squared error and update the running average with the current target.

    Prefix minimizers beat the final fixed leader in cumulative loss.

    Model
    Source V is a subset of real Euclidean space and losses are real on V. The public lemma generalizes to arbitrary ambient type X and total real loss functions; restriction to V recovers the source, and outside-V values are unused when leaders are feasible. No geometry, convexity, compactness or probability premise is required.
    Assumptions
    For EVERY positive prefix n<=T, supplied leader n lies in V and minimizes the prefix sum against EVERY u in V. Both membership and prefix argmin are premises; minimizer existence is not constructed. For T>0 this data implies V inhabited; T0 is a vacuous empty-sum extension with no condition on leader0.
    Algorithm parameters
    Source loss ell_(t+1) is Lean loss t; source x*_n is leader n. Lean diagonal uses leader(t+1) over rangeT; the fixed comparison uses leaderT. T1 has identical sides. Existing induction cancels the final summand, applies the previous prefix inequality, then uses prefix argmin with the feasible next/final leader.
    Regret notion
    A deterministic cumulative-loss comparison between auxiliary hindsight prefix leaders and the final leader; no regret rate or expectation conclusion.
    Guarantee
    The auxiliary hindsight leader at prefix n includes the current loss. It is NOT the causal FTL prediction, which uses the strict past. Lemma1.2 alone produces no learner, no-regret/logarithmic rate, stochastic expectation or minimax theorem. Teaching links to those later results are not actual proof dependencies of this lemma.
