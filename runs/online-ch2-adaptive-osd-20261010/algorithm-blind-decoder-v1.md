## Common context and notation

Universally fix E : Type*, a normed additive commutative group, a real inner-product space, and FiniteDimensional ℝ E. These are the explicit generic instances; no additional explicit completeness hypothesis appears. A Domain V contains a nonempty closed convex carrier K. Write P_K for the supplied nearest-point projection definition. A policy has precisely the type
\[
p:(t:\mathbb N)\to(\operatorname{Fin}t\to E\to\overline{\mathbb R})
 \to(\operatorname{Fin}(t+1)\to E)\to(E\to\overline{\mathbb R})\to E.
\]
It need not be a legal support selector without an additional assumption.

The actual API definitions mean
\[
\operatorname{Proper}(f)\iff
(\forall x,\ f(x)\ne-\infty)\ \land\
(\exists x\,\exists r\in\mathbb R,\ f(x)=r),
\]
\[
g\in\partial f(x)\iff
\forall y\in E,\quad f(x)+\langle g,y-x\rangle\le f(y),
\]
where the inner product is embedded in EReal. Support is global in ambient E, not only on K. SubdifferentiableOn V f means Proper(f) and a nonempty such support set at every x in K. It does not explicitly impose differentiability, a global finite-valued loss, or convexity of the loss as a separate hypothesis.

All definitions take the same fixed parameters V, α,D : ℝ, loss : ℕ → E → EReal, x₁ : E, and p of the above type. Set f_t=loss t. Subscripts below are zero-based: X_0=x₁ despite the parameter's printed name. Real division is total, with a/0=0; EReal.toReal is a total conversion, not a finiteness assertion.

## Eight complete definitions

### A — joint finite history and energy

1. Objects/model: A_t is a pair (h_t,q_t), with h_t : Fin(t+1) → E and q_t : ℝ.
2. Quantifiers: the above parameters are arbitrary; A is defined for every natural t by recursion.
3. Assumptions: no sign, feasibility, support legality, or loss regularity premises are needed to define it.
4. Conclusion/meaning: initialize h_0(0)=x₁ and q_0=0. At transition t form g=p(t,(f_i)_{i<t},h_t,f_t), s=q_t+‖g‖², append x'=h_t(t) if g=0, otherwise x'=P_K(h_t(t)-(αD/√s)g), and set A_{t+1}=(snoc(h_t,x'),s).
5. Constants/indices: transition t appends index t+1; the denominator includes the current squared norm. Fin.snoc retains all t+1 earlier entries.
6. Information/probability: past full functions, actual finite history including current action, and the current full function feed p. There is no probability law or seed.
7. Boundaries/evidence: t=0 has one action and zero accumulated energy. Zero feedback skips projection regardless of whether x₁ is feasible. Negative or zero α,D are permitted in this definition. This is a supplied definition, not a theorem proof.

### H — actual action history

6. Information: it is the history generated by A, not an independently supplied trace.
7. Boundaries/evidence: H_0 is the singleton constant x₁; no feasibility conclusion is part of this definition.
