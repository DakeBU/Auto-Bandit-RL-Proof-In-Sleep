                4.1 Strong Convexity and Online Subgradient Descent
The losses in the guessing game in Chapter 1, ℓt (x) = (x − yt )2 on [0, 1], are not just
Lipschitz. They possess some curvature that can be exploited to achieve a better asymptotic
regret. In a moment, we will see that the only change we will need to Online Subgradient
Descent (OSD) is a different learning rate, dictated as usual by the regret analysis.
   The key concept we will need is strong convexity.


                      4.1.1 Convex Analysis Bits: Strong Convexity
Here, we introduce a stronger concept of convexity that allows us to build a better lower
bound to a function. Instead of the linear lower bound achievable using subgradients, we
will make use of a quadratic lower bound.
Definition 4.1 Let λ ≥ 0. A proper function f : Rd → (−∞, +∞] is λ-strongly convex
with respect to ∥ · ∥ over a convex set V ⊆ dom f if
                                                            1
         f (αx + (1 − α)y) ≤ αf (x) + (1 − α)f (y) − λα(1 − α)∥x − y∥2 ,
                                                            2
for all x, y ∈ V and all α ∈ (0, 1).
   We will also say that f is strongly convex in V , if there exists λ > 0 and a norm such
that the above holds.
  From the definition, it is clear that if a function is λ-strongly convex, it is also λ′ -strongly
convex for any 0 ≤ λ′ < λ. Moreover, convex functions are 0-strongly convex.
  We can also obtain an equivalent characterization in terms of subgradients.
