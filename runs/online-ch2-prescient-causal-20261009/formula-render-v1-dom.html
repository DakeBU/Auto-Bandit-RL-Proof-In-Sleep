    Learning goals

    • Follow the actual projected recurrence and strict-prefix information flow.
    • Keep the negative terminal residual for fixed and decreasing learning rates.
    • Distinguish fixed-step unbounded-domain analysis from diameter-based tuning.
    • Distinguish arbitrary open differentiability neighborhoods from the retained stronger convex-neighborhood predicate.
    • Follow a distinct current-before-prediction affine prescient path, and retain actual movement energy rather than assuming constrained gradient-energy equality.
    • Derive a nonsmooth convex-loss comparison from an actual proximal minimum by differentiating only the perturbation along a feasible segment.
    • Derive canonical Bregman three-point/nonnegative/gradient identities and a nonsmooth proximal one-step comparison with both negative residuals.
    • Derive feasible finite-part convexity, the actual extended proximal minimum equivalence and the signed one-step comparison.
    • Trace a genuine current-loss partial argmin recursion, its exact failure and prefix semantics, and its actual signed one-step bound.

    Algorithm 2.1 with fixed or positive nonincreasing steps

    Read top to bottom: each step supplies the state or proof fact used by the next one.

    1. 01
      Initialize

      Choose x1 in V. Use a fixed positive eta, or a prescribed positive nonincreasing schedule eta_t for a bounded V.

    2. 02
      Predict

      Output the current point before seeing the current loss.

    3. 03
      Read current feedback

      Evaluate the current loss gradient at the current point.

    4. 04
      Project

      Project x_t - eta_t times the current gradient onto V and continue. The fixed-step branch uses the same eta throughout.
