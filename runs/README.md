# Runs

Run directories are generated by `tools/bandit.py run-cycle` and
`tools/bandit.py sleep-run`.

When a reviewer boundary is active, pass `--require-review-response` to
`run-cycle` or `sleep-run`.  The command checks
`tools/bandit.py review-status --require-response` before creating a run deck.

Trial logs:

```text
runs/trials.jsonl
runs/trials_summary.csv
```
