# Code of Conduct

This community is for rigorous, constructive collaboration across mathematics,
machine learning, and formal methods.

Participants must be respectful, explain technical objections with evidence,
credit prior work and contributors accurately, welcome questions from learners,
and distinguish mistakes from misconduct. Harassment, discrimination, personal
attacks, intimidation, plagiarism, deliberate misrepresentation of proof
status, and publication of private information are not acceptable.

When a discussion becomes unproductive, maintainers may pause it, request a
more precise technical statement, hide harmful content, or restrict
participation. Report conduct or privacy concerns privately to the repository
owner through the contact method listed on their GitHub profile. Do not put
sensitive personal information in a public issue.

Good-faith technical disagreement is welcome. The standard is not agreement;
it is a clear, evidence-based, and humane review process.
