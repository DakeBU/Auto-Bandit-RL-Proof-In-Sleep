# Conversion Window: Explore-Then-Commit regret route

Task id: `BRL-ETC-PORT-001`

Source card: `TXT-LATTIMORE-SZEPESVARI-2020`
Scenario card: `SCN-STOCHASTIC-FINITE`

## Natural-Language Statement

Explore-Then-Commit pulls each arm a fixed number of times, commits to the arm
with the largest empirical mean, and pays regret through exploration plus the
probability of committing to a suboptimal arm.

At the recorded LML seed, `Bandits.ETC.regret_le` is stated for a Real-valued
stationary kernel environment and an arbitrary process satisfying
`IsAlgEnvSeq`. It assumes a common per-arm `HasSubgaussianMGF` proxy and bounds
expected regret by the per-arm sum
`sum a, gap a * (m + (n - K*m) * exp (-m * gap a^2 / (4*sigma2)))`.
The local bounded Rat/max-gap theorem is a specialization, not an exact type or
constant match.
